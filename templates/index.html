Classical vs Quantum (VQC) comparison

Trains a Logistic Regression model and a 4-qubit Variational Quantum Classifier (RY feature map, CNOT entanglement, RX ansatz, COBYLA optimizer) on the same data, then compares them. Takes ~20-30 seconds.

Note: this is an educational/demo comparison. A shallow 4-qubit VQC with a single trainable layer typically has less representational capacity than a classical model on this dataset, so it's normal to see the classical model score higher.
